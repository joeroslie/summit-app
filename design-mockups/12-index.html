Summit, wearing five different worlds

Each sample below is a direct structural reproduction of one specific reference screenshot — same composition, same signature chart types, same card shapes — with Summit's real content standing in for the demo data. Not a recolored dashboard template five times over.

Revised after v1 feedback. The first pass reused one generic topbar/stat-grid/card-grid scaffold across all five files and only swapped accent colors — that's the exact "same-size cards as page structure" pattern the craft floor bans, and none of it actually looked like the screenshots. This pass rebuilds each sample from its reference's real signature elements: RealtyHub's striped/solid progress bar and capsule bar chart, SugarCRM's SVG flowchart connectors and donut charts, Salesforce's cost-breakdown grid and payout chips, the mobile app's full-width color stack at its own phone width, BizLink's dashboard-summary- plus-kanban composition in one screen.
