# Page chats

**Rule:** If you’re working on a page in the app, open the chat with that page’s name.

1. New chat → rename to the name below  
2. Pick the model  
3. Open the matching `.md` file → copy **Starter** → send  
4. When the slice is done, delete or leave idle — prefer **1 active** agent, not a farm  

Chat names are **area-only** (no product brand prefix) so a rename doesn’t touch every file.
